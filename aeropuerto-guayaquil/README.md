# Aeropuerto de Guayaquil

App web responsive con búsqueda y filtros para vuelos reales de GYE mediante AirLabs.

Abre `index.html`, pulsa **Conectar datos reales** e ingresa una clave gratuita de AirLabs. La aplicación no contiene vuelos inventados: sin conexión al proveedor, el tablero permanece vacío.

Dominio previsto: `https://aeropuertogye.com/`. El dominio debe registrarse y conectarse al hosting mediante DNS antes de que la URL sea pública.
